# Bike-Sharing-ML
# Bike Rental Demand Prediction 🚲

This project focuses on predicting the number of bike rentals using historical hourly bike-sharing data. The dataset contains information about time, season, weather conditions, temperature, humidity, wind speed, and working days.

Several Regression Machine Learning models were trained and compared, including Linear Regression, KNN Regression, Decision Tree, Random Forest, Gradient Boosting, and XGBoost.

The models were evaluated using MAE, MSE, RMSE, and R² to compare their prediction performance. The project also includes Exploratory Data Analysis, feature importance analysis, model comparison, actual vs. predicted visualizations, and predictions on new data.

### Main Topics

* Data Exploration & Visualization
* Data Preprocessing
* Feature Analysis
* Regression Models
* Hyperparameter Tuning
* Model Evaluation
* Feature Importance
* Prediction on New Data
